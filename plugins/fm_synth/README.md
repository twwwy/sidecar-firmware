# FM Synth

Personal Sidecar user machine project for the Raspberry Pi Sidecar.

The sound design and controls are still to be defined. Add the machine source,
`Makefile`, and `manifest.json` here, following `plugins/sc_acid` and the
[user machine guide](https://trigcondition.github.io/sidecar-expander/developers/writing-user-machines/).

Build an AArch64 package from the repository root with
`make -C plugins/fm_synth a64` once those files are in place.
